# wttg3-assistant

![Assistant Icon](/Assets/icon-bar.png)

The Welcome to the Game 3 Assistant is a tool for learning and beating the game "Welcome to The Game 3". It includes interactive resources and other information about the game. 

**Please click the following link if you want to use the assistant. [Open the Assistant](https://otrexdev.github.io/wttg3-assistant/)**  
**If you wish to get in touch for bugs, questions, or feature suggestions please open an issue.**
